How to install in Gmail

  1. Click Copy signature above
  2. Open Gmail → Settings (⚙) → See all settings → Signature
  3. Create a new signature or edit an existing one
  4. Click inside the signature editor and press Ctrl+V (or Cmd+V on Mac)
  5. Click Save Changes

Banners

Gmail does not accept images embedded in a signature, so each banner is stored in the GitHub repo and shown from there. Use Upload image on a banner (needs the GitHub token below), or paste the link of an image that is already online. Export the image at 2× the size you want to display so it stays sharp on retina screens. Only active banners that have not expired appear in the dropdown for staff.

Saves the banner list in the repo. Staff see the change once GitHub refreshes the site, usually within a few minutes.

GitHub connection

The token lets this page save banners and images to the repo. It is stored only in this browser, never in the file. Create it on GitHub: profile photo → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token. Under Repository access choose Only select repositories → MMA_Signature, and under Repository permissions set Contents: Read and write.
